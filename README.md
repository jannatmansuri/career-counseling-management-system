# Career Counseling Management System (CCMS)

## About the Project

CCMS is a web-based career counseling application that allows users to explore career options, view experts, and submit consultation requests.

It also provides an admin panel to manage careers, experts, and consultation requests.

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5.3
* JavaScript
* Core PHP
* MySQL
* Chart.js
* XAMPP

## Features

* User registration and login
* PHP session-based authentication
* Career listings and details
* Expert listings and details
* Consultation requests
* Admin dashboard
* Career and expert CRUD operations
* Consultation status management
* Dashboard charts and statistics

## How to Run Locally

1. Install XAMPP.
2. Copy the project into the XAMPP htdocs folder.
3. Start Apache and MySQL.
4. Create the MySQL database named `ccms_wfs`.
5. Import the database schema if a sample schema is provided.
6. Configure the database connection using your local credentials.
7. Open the project through localhost in your browser.
